XTRM-853 · Console v2 · design pass

The Console UI system: one rail, quiet toolbars, small rows, PR identity, Project visuals, one Factory drawer

The operator's review of 2026-11-18 asked for a coherent UI system before more surfaces land. This page shows the six answers in the Console's own tokens, in light and dark. The committed spec packages/xtrm-app/docs/design/console-ui-system.md names every token and component, with file, props and consuming surfaces.
