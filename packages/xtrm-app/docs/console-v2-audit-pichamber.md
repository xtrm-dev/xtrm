## 2. Architecture map — VERIFIED

- Layout: `packages/{web,ui,electron,mobile,docs}/`, `docs/`, `scripts/`, `Dockerfile`, `docker-compose.yml`, `Caddyfile`. Runtime: React `^19.1.1`, Vite `^7.1.2`, Tailwind `^4.0.0`, Zustand `^5.0.8`, TS `~5.9.0`, Electron `^41.2.1`, `electron-builder ^26`, `electron-updater ^6.8.3`. Pi SDK pinned exact: `@earendil-works/pi-coding-agent 0.85.1` (daemon docs mandate per-minor re-validation on upgrade).
- **Electron, not Tauri.** Desktop = `packages/electron` (`main.mjs` 50KB, `preload.mjs`, `tray.mjs`); targets dmg+zip / nsis / AppImage+deb+rpm; publishes to GitHub releases. `packages/web` = Node/Bun HTTP server (Express `^5.1.0`, `ws ^8.18.3`) + Vite SPA in one package; `bin/cli.js (pichamber serve)` launcher. `packages/ui` = rich React client source (private, not a library). `packages/mobile` = Capacitor shell, version `1.13.2` vs siblings `1.0.1` (drift VERIFIED).
- Pi ownership split (README, quote-paraphrase): PiChamber owns workspace, auth, device connections, native shells; Pi owns sessions, providers, prompts, skills, extensions, themes, session daemon behavior. Enforcement: `packages/web/server/lib/pi/session-daemon/` — detached local daemon creates `AgentSessionRuntime` behind a **private** Unix-socket/Windows-named-pipe IPC (`daemon-process.js`, `ipc-protocol.js`, `supervisor.js`); "Browsers never connect to it". Public `lib/pi/routes.js` is a whitelisted adapter; no browser response contains daemon paths/credentials/PIDs. PiChamber overlays that never touch Pi JSONL: `archive-store.js` (sidecar), `settings-store.js`, `ui-settings-store.js`, `session-folders-store.js`, `snippets-store.js`, `custom-themes.js`, `model-config-store.js`.
- Data dirs: Pi owns `~/.pi/agent/`; PiChamber owns `~/.config/pichamber/` (+ override); OpenChamber dir not migrated.
- Session routes (`routes.js`, VERIFIED via grep): list/create/open, `GET snapshot/messages/tree`, `POST navigate/fork/clone/send-receipt/compact/archive`, `PATCH` rename, `DELETE`; prompt/steer/followUp/abort/model/thinking via private core commands. Mechanics: list = cwd-scoped JSONL **header-only** scan (SDK `list` avoided for cost); open = full-file validation + hydrate with live-turn overlay + tail page; 16 MiB IPC frame cap; `messages` paging with opaque `before` cursor; fork/clone = server-side branch ops; archive = sidecar bit only; delete = explicit `session.deleted`; resume = per-event sequence + opaque `streamEpoch`, 1,024-event/8 MiB replay ring, stale epoch → authoritative `session.snapshot` with `resync:true`; live `message_start` synthetic IDs rebound at `message_end` (`message-entry-aliases.js`); send safety = `send-operation-registry.js` (`kind+sessionId+operationId+streamEpoch` claimed before activation; 409 mismatch / 410 expired); residency = `session-lease.js` exclusive lease + 5-min idle disposal (never while streaming/compacting/retry/dialog-pending); standalone `pi` CLI ignores leases — concurrent PiChamber+CLI edit unsupported (deliberate limit).
- Remote/device model: three-layer relay design (L1 outbound-WS routing, L2 WebCrypto ECDH+AEAD with out-of-band pairing trust anchor, L3 tunnel mux) — but **the relay host runtime is not started by any runtime entrypoint at this SHA** (`createRelayService` entrypoint + `host-lock.js` removed as dead code). Design is sound and well-documented; do not score remote-relay as shipped. Operable paths: direct LAN/tunnel + pairing.
- Auth: one durable credential (remote-client bearer `oc_client_…`, stored hashed, returned once); password, WebAuthn passkey (`@simplewebauthn/server 13.3.1`/`browser 13.3.0`, `jose ^6.1.3`), and Pairing v2 are **issuance methods**; 60-second encrypted `oc_url_token` for header-less WS/SSE establishment; JWT secret read-once at startup; global sign-out rotates; single-server only.

## 3. UI audit — VERIFIED paths, judgments marked

- Session navigation (`components/session/SessionSidebar.tsx` + `sidebar/`, ~10 hooks): flat unified recency order; fork families = deterministic per-family accent color from family-root ID (no nested fork tree); archived list virtualized; pins/ordering/folders/spaces/switcher/mobile sheet. Judgment: interaction genuinely good for large counts; implementation heavy (~15 hooks + 3,168-line `apps/pi-session-store.ts` + `sync/` + `stores/` duality) — onboarding cost is high.
- Live reasoning/tool/token pipeline (`lib/pi/client.ts` 924 lines → `event-reducer.ts` + `reducers/` → `pi-session-store.ts` → `components/chat/`): server-enforced token/usage sanitizer; alias-resolved live IDs; tool renderer metadata (diffs, truncation notes, server timestamps + `serverNow` normalization); compaction/retry lifecycle preserved. Strongest area — protocol engineering, not theming. Deduction: overlapping "working" indicators (`WorkingPlaceholder`, `TurnWorkingHeader`, `AgentThinkingLoader`, `MinDurationShineText`) should be unified; `StatusRow` doubles as todo renderer.
- File/project navigation (`components/views/FilesView.tsx` + `files/`, `FileViewerContent.tsx`): embedded/fullscreen viewer with CodeMirror 6 edit, Pierre-diff preview, markdown/diagram/JSON-tree/image/PDF/binary branches, worktrees, Git views. Capable but unrestrained: CodeMirror **and** Shiki **and** Pierre = three rendering stacks; two markdown libs in monorepo (`marked ^17.0.3` in ui, `react-markdown ^10.1.0` at root — INFERENCE).
- UI package organization: `packages/ui/src/` (`App.tsx`, `apps/`, `components/` incl. `chat code icon icons layout model-picker perf session terminal ui views worktree`, `contexts/ hooks/ lib/ stores/ sync/ types/`). `components/ui/` primitives on **Base-UI + full Radix set** + `cmdk ^1.1.1` + `sonner ^2.0.7` + `cva` + `next-themes` + `@dnd-kit/*` + `motion ^12.23` + draw/diagram libs — two primitive systems is the anti-pattern; DEPEND on one family only.
- Command palette: `CommandPalette.tsx` on `cmdk` + Radix Dialog, fuzzy files+sessions+settings+desktop-menu actions, `fuse.js ^7.1.0`. Competent and conventional — well-wired, not distinctive.
- Code/file rendering: markdown pipeline (`markdownCore/Security/StreamBlocks/Theme`, `markdown-worker.ts`, `markdown-shiki.worker.ts`, Mermaid/draw.io/KaTeX, DOMPurify) + `shiki ^3.23.0`; editing CodeMirror 6 (view `6.39.13` + language `6.12.2` pinned via overrides, ~12 packs, vim); diffs `@pierre/diffs 1.3.0-beta.6`; terminal `@xterm/xterm 6.0.0` + pty (`bun-pty`, `node-pty 1.2.0-beta.12`). High output quality, heavy stack, beta diff dep.
- Icon system: sprite-based (`components/icon/` + `components/icons/` + `scripts/generate-*-sprite.mjs`, centralized file-type sprite IDs) on `@remixicon/react ^4.7.0`. Genuinely good — reference-worthy.
- Performance: `virtua 0.49.1` **and** `@tanstack/react-virtual 3.14.5` (both declared + a virtual-core patch) — dual libs read as accretion; markdown in worker; `VirtualizedCodeBlock`; `useDeferredExpandedContent`; bounded transcript pages + `before` cursor + viewport anchoring; SSE 8 MiB bound; JSONL header-only list; `perf/` + profiling scripts. Main-list window virtualization UNKNOWN (paging VERIFIED, windowing only for archive/code blocks) — do not cite as "fully virtualized chat". Budgets-at-every-layer thinking is genuinely good.

## 4. Critical comparison (INFERENCE unless noted)

Genuinely above the bar: daemon isolation + IPC discipline; reconnect/send correctness (epoch replay, alias-resolved IDs, 409/410 idempotency, lease residency); bounded-everywhere budgets; icon-sprite discipline.
Merely Pi-native or below "restrained": 3k-line session store + ~15-hook sidebar; Base-UI **and** Radix, `marked` **and** `react-markdown`, `virtua` **and** TanStack Virtual; family-color fork UX (elegant small-scale, low ceiling vs explicit branching); relay unwired (VERIFIED); mobile/Capacitor/PWA/STT/diagram matrix explosion; beta/pinned fragility (Pierre beta, CodeMirror pins, node-pty beta, Electron 41).
**Net: protocol/runtime engineering exceeds the bar; UI structure does not meet "restrained". Borrow the former; adapt the latter selectively.** Do not assume Pi-native = better — Supernova's single-stack restraint (one markdown lib, one virtual lib, one primitive family, no mobile matrix) is the cleaner structural reference.
