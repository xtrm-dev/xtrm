What the Linear reference changes

Measured from the supplied screenshot (594 × 2044, @2x).

Row geometry
30 px row, 16 px icon, 20 px indent for team children — variant B matches Linear exactly.
Stroke
Linear draws 1.5 px at 16 px. B uses 2.0: heavier than Linear on purpose, since the brief asks for more weight than today's 14 px / 1.6.
Label weight
Linear is 13 px / 500, the same as our current sidebar. Weight 600 is a deliberate step beyond the reference.
Section headers
No glyph, muted 12.5 px text, small filled caret after the label. Our proposal keeps a stroke chevron and no glyph.
Icons are all muted
Linear tints every nav icon grey and lifts only the label on the active row. Ours tints the icon to ink on the selected row.
Semantics to borrow
Issues = stacked squares (square-stack), Projects = isometric cube (box), Agent = cursor arrow (mouse-pointer-2), My issues = viewfinder (scan).

Revised icon questions

The reference creates three real alternatives to the recommendation.

Issues. Linear's nav Issues is square-stack; circle-dot is its status glyph. Keep our CircleDot (status semantics) or follow the reference with SquareStack. square-stack

Program. Linear's Projects is box (isometric cube with inner Y). Closest reference-consistent glyph for Program. box

Agents. Linear's Agent is a cursor arrow, not a robot. mouse-pointer-2 reads lighter and more "doer". mouse-pointer-2

Section caret. Filled triangle after the label (Linear) or stroke chevron pinned right (our proposal). triangle · chevron-down
