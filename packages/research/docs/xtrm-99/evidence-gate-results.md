# Evidence Gate results (XTRM-499, XTRM-510, XTRM-511; criteria 3, 4, 6)

The Evidence Gate decides which retrieved candidates (ctx_search passages,
researcher web results) reach a frontier agent's context. The policy
priority is useful-evidence recall first, then reduction (XTRM-99 §2).

This document reports two different experiments on the same frozen set.
Do not read one as the other.

| Part | Question | Pattern |
|---|---|---|
| A (XTRM-499) | Can a local model, Jev, or an LLM reproduce the reference label as a holistic per-candidate classifier? | classifier against classifier |
| B (XTRM-511) | Does the System One pattern (a battery of atomic questions composed by code, with selective escalation to an LLM) keep the LLM gate's quality while calling the LLM less? | System One control flow |

Every table below is generated by
`python -m xtrm_research.evidence_gate.report RESULT.json [--cascade]`, never
transcribed. Every value carries a 95% cluster-bootstrap interval (2000
resamples, seed 20260918, clusters = source_ref). Parts A and B use the
same resamples, so their deltas are paired.

## 1. Dataset and reference labels (criterion 3)

- Dataset `evidence-gate` version 2: 265 candidates from real XTRM search
  workloads (Pi `ctx_search` 88, Claude `ctx_search` 86, Specialists
  researcher `ddgs` 91), items sha256
  `821eca67f248570e0f65ab111eba15e7654cd5d2289217d030886bab86c7d859`.
  Provenance, selection and filters: `registry/dataset/evidence-gate-v2.json`
  and the write-once manifest at `~/.xtrm/research/datasets/evidence-gate-v2/`.
  Version 2 is version 1 with `passage_source` redacted (12 items changed);
  version 1 is superseded.
- Labels: two non-Anthropic labelers (`gpt-5.6-luna`, `gemini-3.7-flash`),
  adjudicator `Kimi-K2.6`, context-isolated pi calls. Label version
  `sha256:83182b7ff1928c8abc88597a5475de701879e38e254107c7e734ec353c668a42`,
  labels sha256
  `sha256:2e43fdb252c1093052d65e913c0b2f930698c471b0767028a585281ee6be5593`.
- Labeler agreement (Krippendorff alpha, nominal, 95% CI): usable evidence
  0.678 [0.572, 0.771]; relevant 0.690 [0.565, 0.792]; source authority
  0.635 [0.483, 0.753]; warrants attention 0.630 [0.511, 0.731].
- Class balance (labeled): usable evidence 153 / 82 (30 unlabeled);
  contradiction 0 positives; prompt injection 2 positives.
- Evaluation set: 222 items in 78 clusters. 43 items are excluded because
  they have no final label on at least one question.

Limitation: the labels are LLM-adjudicated, not outcomes. An arm from the
same model family as the labelers may be favoured.

## 2. Part A: holistic classifiers (criterion 4)

Arms: `embedding` (bge-small, CPU), `qwen` (Qwen3-Reranker-0.6B raw
P(yes), CPU), `jev` (TypeSafe jev-1.13.0, six questions per request),
`frontier` (Claude Sonnet 5, effort low), `llm` (DeepSeek-v4.1-flash through
pi). Each gate is thresholded out-of-fold at the 0.95 recall target
(`calibration.md`).

## 3. Part B: the System One cascade (criterion 6 input)

- **Battery.** One Jev request per candidate carries 12 atomic noul
  questions, for example `same_subject`, `answers_part_of_query`,
  `has_code_or_command`, `is_navigation_or_chrome` and `is_cut_off`. No
  question asks the target construct itself. The text is in
  `src/xtrm_research/evidence_gate/cascade.py` (`BATTERY_TEXT`); the specs
  are registered as `evidence-gate-battery.*`.
- **Composition.**
  - `battery-rule`: a soft-logic rule fixed before any answer was seen,
    Platt-calibrated.
  - `battery-learned`: L2 logistic regression on the answer logits.

  Both are fitted out-of-fold on the grouped folds of Part A.
- **Cascade.** `battery-learned` plus a band fixed before the evaluation,
  fitted per training fold:
  - reject below the threshold that keeps 0.98 recall;
  - retain at or above the lowest threshold with 0.95 precision;
  - escalate everything between to DeepSeek.

  The escalation is a **replay** of the recorded `llm` arm answer and its
  out-of-fold decision. It charges that answer's recorded cost and latency,
  and makes no new call.
- **The nine band cells marked "exploratory" are a sensitivity sweep.** Any
  cell other than the pre-registered one was chosen after the results were
  seen and is not a finding.
- **Spend:** 265 Jev requests, 233,096 input tokens, USD 0.0098.

n_eval = 222 items in 78 clusters; battery `sha256:c3831df4697d157321e4567f50b6ed54cc25b3df25856ffb9c5cc3ae3e315780`; pre-registered band {"hi_precision": 0.95, "lo_recall": 0.98, "min_retained": 5, "ridge": 1.0}; uncached requests at evaluation 0.

## 4. Reading

The following statements are facts, read from the intervals above:

1. **Holistic Jev is below both LLMs on ranking quality.** Usable-evidence
   AUC minus DeepSeek is −0.099 [−0.142, −0.058]; minus Claude it is −0.106
   [−0.154, −0.060]. Jev is above the local reranker and the embedding.
2. **Decomposition alone does not measurably improve Jev.** The difference
   from holistic Jev is +0.021 [−0.035, 0.073] for the rule and +0.012
   [−0.046, 0.070] for the learned composition. Both intervals include 0.
   The battery is cheaper and faster than the holistic request: USD 0.037
   vs 0.047 per 1000 candidates, 636 vs 734 ms p50.
3. **The pre-registered cascade matches the DeepSeek gate on precision.**
   The difference is +0.007 [−0.005, 0.023], and it cuts more frontier
   input tokens (+0.028 [0.005, 0.059]).
   - It sends 61.3% [51.5%, 70.1%] of candidates to DeepSeek, not 100%.
   - It costs USD 0.188 [0.129, 0.255] less per 1000 candidates.
   - It **loses recall**: −0.027 [−0.053, −0.007]. The gate's first
     priority is recall, so the pre-registered cascade does not meet the
     §2 policy as well as the DeepSeek gate does.
4. **Claude remains the best gate on precision and reduction.** The price
   is USD 8.79 per 1000 candidates and 8.3 s p50.

Inference, not verified: exploratory band cells with a lower precision
ceiling (for example lo98/hi90) keep recall at 0.966 [0.930, 0.993]. They
escalate 28% of candidates at USD 0.232 per 1000. A pre-registered
replication on new data is required before this is a finding.

## 5. Not established

- Contradiction preservation and injection rejection: 0 and 2 positives
  (fewer than 10). The policy paths are disabled and no metric is reported.
- End-to-end answer quality of the downstream agent, with and without the
  gate.
- Cost of the local arms: CPU on the operator host, not metered.
- Calibration-fit variance: the intervals resample evaluation items only,
  so they are a lower bound on the uncertainty.
