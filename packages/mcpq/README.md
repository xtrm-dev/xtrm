# mcpq

Lightweight CLI for querying Docker-network-only MCP sidecars from the host.

## Status

Phase A scaffold. Full documentation lands in a later phase.

## Install (dev)

```bash
pip install -e packages/mcpq
mcpq --help
```

## Quick start

```bash
mcpq servers                # list configured servers from .mcpq.json
```

Subcommands `list-tools`, `describe`, `call` are placeholders until Phase B.
