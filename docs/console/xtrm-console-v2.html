scope mixed auth and logging · failure pattern

type:failure instances: 3 first seen: Jun 6 last: 2h ago watch

Distilled pattern

Chains that touch auth and logging in the same scope get rejected at review: the reviewer cannot attribute findings to a single concern, and the diff is unreviewable as one unit.

Aggregated body: split the scope before opening the chain — one chain per concern. The coordinator should reject mixed-scope seeds at composition time; the reviewer rejecting at gate time is the expensive path.
